# 「穿点啥」AI 男性穿搭助手 —— 可运行 Demo

> 面向 20-35 岁男性：输入身材参数 + 上传人脸 → **真实大模型**生成 7 天穿搭 → **真实图像生成**试穿图 → 展示真实商品卡片（商品名/价格/图片/购买链接）。

---

## 1. 在线 Demo（推荐直接体验）

- 前端（UI）：**https://aadc89cadf0f.aime-app.bytedance.net**
- 后端（API）：**https://n9xisupv.cn-east-fn.bytedance.net**

说明：
- 前端默认已指向线上后端；你也可以在页面里改 `API BASE (CONFIG)`，或用 URL 参数临时覆盖：
  - `https://aadc89cadf0f.aime-app.bytedance.net/?api=https://n9xisupv.cn-east-fn.bytedance.net`

---

## 2. 重要说明（关于“必须真实 AI”与隐私）

- **穿搭推荐**：后端会真实调用大模型生成（并采用“生成 → 若 JSON 不可解析则让模型自修复”的双轮策略，仍然属于真实模型能力）。
- **虚拟试穿图**：后端会真实调用图像生成能力（按你要求“速度优先”，只要看起来像穿着那套衣服即可）。
- **电商商品**：优先展示已抓取的真实商品卡片（京东/淘宝/拼多多：商品名/价格/图片/购买链接）；若某单品未命中缓存，则兜底为对应平台搜索入口。
- **照片不落库**：后端仅在 `/api/tryon` 请求里使用你上传的照片做生成参考，不做持久化存储；穿搭方案会在内存中临时缓存（TTL=1h）用于试穿。

---

## 3. 最小验收步骤（线上）

1) 打开前端：`https://aadc89cadf0f.aime-app.bytedance.net`
2) 填写身材参数 → 点击「生成一周穿搭」
3) 确认返回 7 套（不同参数应产生不同风格/细节的方案）
4) 上传人脸照片 → 选择某一天 → 点击「生成试穿图」
5) 点击任意商品卡片，可跳转到对应平台商品页/详情页（或搜索入口兜底）

## 5. 已知边界 / 风险

- **图像服务可能偶发繁忙**：若试穿图生成返回 503 / 429（资源不足），这是图像服务资源池忙导致的真实失败，不是模拟数据。建议直接点「重试」，或稍等 10-30 秒再试。
- **商品卡片当前优先用“已抓取缓存”**：能保证展示的是“真实商品数据”，但不保证一定与当次生成方案完全同款；未命中缓存会兜底到平台搜索入口。
